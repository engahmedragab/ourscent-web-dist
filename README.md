# ourscent-web — build output

Compiled static assets for **OurScent (عطرنا)**, published here only so
DigitalOcean App Platform can serve them.

- Generated by `npm run build` in the private `ourscent-web` repository.
- **Do not edit by hand** — changes here are overwritten on the next deploy.
- Contains no source, no sourcemaps and no secrets: exactly the files a browser
  downloads when visiting the site.
